# Приёмка после появления игры

До явного подтверждения готовности входной файл не читаем. Не используем частичный download.
Команды выполняются из корня проекта, Python 3.10+, без дополнительных пакетов.

```powershell
New-Item -ItemType Directory -Force private, work | Out-Null
python scripts/intake.py image --input-complete --input "private/Drakengard-Europe.iso" --output "work/intake-image.json"
```

Укажите фактический путь своей копии. Команда потоково считает SHA-256 и размер; проверяет,
что файл не изменился за время чтения. Это fingerprint, а не верификация диска/ISO filesystem.
Инструмент не принимает compressed CHD/CSO или raw BIN вместо ISO.

Локально извлеките ISO отдельным проверенным ISO-инструментом в `work/extracted/`.
Не запускайте извлечённые файлы на host и не меняйте оригинал. Запишите название/версию
extractor и команду в локальном журнале. Извлечение этим репозиторием пока не автоматизировано.

```powershell
python scripts/intake.py tree --input-complete --input "work/extracted" --output "work/intake-tree.json"
```

Проверяется SYSTEM.CNF/BOOT2 (ожидаемый SLES_523.22), boot ELF32 little-endian MIPS,
PT_LOAD bounds, точка входа в executable segment; считаются SHA-256 ELF и SYSTEM.CNF.
BOOT2 должен ссылаться внутрь извлечённого каталога. Отчёт включает inventory имён/размеров,
но не читает все ресурсы и не устанавливает, что дерево действительно получено из данного ISO.
Эту связь и хеши ISO/ELF надо сохранить вместе при фактической приёмке.

По умолчанию отчёты сохраняются только в ignored work/ и не перезаписываются.
Любая ошибка завершает CLI ненулевым кодом; она не означает поддержку другой ревизии.
Отчёты могут содержать личные пути: не коммитить. В публичное состояние переносить лишь
вручную проверенные идентификаторы, хеши, метаданные и выводы без содержимого игры.

После intake: PCSX2 baseline, затем docs/ROADMAP.md M2. Не начинать lift по предположенным
адресам и не считать совпадение serial доказательством совпадения ELF.
